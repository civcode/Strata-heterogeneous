CUDA adoption state is separately checked with the existing observer. The reference reruns CUDA native prefill, independently feeds HIP0 and HIP1 the captured producer output of the matching wire run, and does not forward any live bulk residual between stages. Both prefill-completion ACKs precede continuation; ordinary teacher-forced verifier continuation still uses the real mixed runtime path. Stage-local native replay shares native Prefill and resource loaders and is not a standalone full original vanilla caller. Stage scheduling differs; mismatch must be diagnosed, not automatically labeled a transport fault.

New host reader/writer bounds 16 rows and width 10240; requires finite data, exact regular-file size/EOF, exclusive output, rejects symlinks. Capture/reference is explicit, A/B/A request 2 only, original 12/18/18 plan/context, chunk <= cut <= 16, no first-token HC replay, MTP or ordinary resident generation. Reference source pairing is validated offline; marker existence is not proof of trusted data. Same immutable local source and actual logs/configs are required. No new physical suffix erasure claim.

Serial quality uses unchanged MAX_KL=.001 and exact prediction/top-1 rules; neither axis can waive the other. Even a matrix pass explicitly leaves production admission NOT_QUALIFIED.
