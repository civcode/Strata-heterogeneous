# Strata heterogeneous project instructions

The mandatory cross-project development rule is [.ai/VANILLA_FIRST.md](.ai/VANILLA_FIRST.md).
Read it before modifying any native Strata engine, heterogeneous integration,
CLI/server, performance tool or configuration. Follow
[the performance roadmap](.ai/PERFORMANCE_ROADMAP.md),
[the implementation contract](experimental/heterogeneous/docs/IMPLEMENTATION_CONTRACT.md),
and [the test budget](.ai/TEST_BUDGET.md). Directory-specific instructions in
[experimental/heterogeneous/AGENTS.md](experimental/heterogeneous/AGENTS.md)
remain applicable. The current owner direction is authoritative over historical
milestone proposals and superseded handoffs. Local validation only; no Actions
execution without explicit owner authorization.
