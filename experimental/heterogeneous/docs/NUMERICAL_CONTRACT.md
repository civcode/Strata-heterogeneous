# 0030 — numerical contract and performance constraints

Keep native CUDA/HIP workers, process isolation, existing layer partition and lossless FP32 R transport, residency, and optimized kernels. Default auto mode unchanged. Logical model source and actual operand representation are distinct. Identical source fingerprints do not prove identical effective weights. HC Q8 on gfx12 is a deliberate vanilla value-changing speed choice, not a transport error. Explicit BF16 and Q8 diagnostic contracts use existing STRATA_HC_Q8=0/1, with STRATA_HETERO_HC_WEIGHT_CONTRACT=bf16/q8 marker. Marker attests request only; verify actual loader and projection pointers, original GGUF/pack representation, shape, missing copies, per-owner memory and mode. Q8 may be stored original format or generated at load; do not equate the two without inspecting bytes. No default switch, no relaxing guarded FP32/BF16x2 modes, no bulk+MTP or reverse grouped changes.

Common operator semantics: same stored weights or declared effective representation, same token IDs/position, initial residual/state, norm epsilon, nonlinear functions, routing mask/tie policy, recurrence and committed state, final head. Permit implementation-specific reduction order and optimized fused kernels; compare actual operands against FP64 algebra and actual full logits. Distinguish local representation, accumulation and propagated errors. Native prefill/serial and topology comparisons separate. Mandatory bounded gate remains max KL <=.001, exact prediction/top1 and independent repeatability/transport/state/ref. Statistical NLL/perplexity, mean/max KL and top1 extend evidence, never waive failure. PPL from next-token teacher forcing only, same tokenized text and document resets; no selected generated-token PPL. No production admission on an aggregate or a synthetic reference.

Performance: compare same model, tokens, dispatch other than declared intervention, topology, cache/residency, clocks, warmup and synchronization. Measure startup separately, per-owner prefilling/serial latency, sustained prompt and generated throughput separately, memory baseline/peak/reserve with instrumentation observer check. Record raw repeats and medians/ranges. Prefer accuracy improvements with no meaningful performance regression; no arbitrary budget imposed. Report Pareto tradeoffs, do not change defaults without review. The existing Q8 optimization's source comments report speed benefit on gfx12, not measured by this handoff. Short cut timings cannot stand in for long workload throughput.

CPU tools: imported 0029 oracle and report; new statistical completed-placement capture adapter and qualification summary. Matched operand GPU capture/replay framework is not complete: use existing HC CUDA replay and all-layer trace for initial attribution, add actual HIP replay with shape/format/owner/state/fence proof before asserting matched backend behavior. Raw stored weight/operand data only local. Statistical corpus capture uses existing bounded serial placement; wider representative workloads and native bulk corpus adapter remain separate implementation/validation tasks. No claim of reasoning quality from these metrics.
