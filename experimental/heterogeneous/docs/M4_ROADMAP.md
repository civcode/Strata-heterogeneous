## Usage

Use existing M3.5 CLI flags and authorized stage config paths. Add `--resident --benchmark-repeat 3 --output json` for repeated independent prompts; add `--prompt-chunk 0`, `--max-context 8192` or `--stream-tokens` only for corresponding qualification. Preflight without `--run`; live operations only within explicit approval. Benchmark JSON reports per-request timings, startup/shutdown and effective context/chunk. Exclude startup from warm request throughput; first-prediction wall time includes prefill, IPC and ACKs, and worker reset when applicable, not client/network TTFT. Decode throughput counts committed feedback rows, not the last predicted token. Default context now consistently means prompt plus requested completion, including one-shot CLI; explicit larger limits remain bounded by model capacity and serialized input.

If passive telemetry is authorized, use `.venv/bin/python -m tools.heterogeneous_telemetry --device cuda:0 --device hip:0 --device hip:1 --interval 1 --duration 180` in a separate terminal, with the actual monitor indices independently mapped to the plan's PCI IDs. Save JSONL under the staging directory; null measurements are unavailable, not zero. Reader indices are not assumed equal to backend-local worker ordinals. Take a baseline, samples during generation and after ordinary cleanup. The sampler only reads existing telemetry, not GPU diagnostics or stress tests.

For deployment replace prompt options with `--write-server-config /absolute/new/server.json`; include desired opt-ins, optionally `--restart-clean` (off by default). CPU preflight reads the authorized tokenizer/template and validated config; no GPU startup or overwrite. Launch explicitly via `STRATA_NO_HANDOVER=1 .venv/bin/python -m serve.server --engine heterogeneous --config /absolute/new/server.json --host 127.0.0.1 --port 0 --offline`. Existing server owns shutdown. Streaming can expose committed partial text before a later failure; only a valid final completion confirms request success. Do not auto-retry an HTTP request after partial output.
